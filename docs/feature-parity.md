# 高機能ファンベースサイト機能一覧

NSWER JAPAN FBは独自の外見と色を維持しながら、安定運営に必要な以下の機能を備えます。

- 共通ヘッダー・フッターの一括生成
- ニュースから静的記事ページを生成
- ページ別OGP画像、canonical、構造化データ、サイトマップ
- PWA、オフライン画面、キャッシュ更新
- 日本語／韓国語／英語
- サイト内検索、お気に入り、共有
- スマートフォン向けレスポンシブ表示
- スケジュールとICS配布
- 音楽番組1位、Melon、Hanteoの記録ページ
- ディスコグラフィ、MV、配信・購入リンク
- YouTube通常動画・Shorts・ライブ配信アーカイブの全履歴取得
- 外部リンク検査と検査結果ページ
- 更新履歴、データ状況、分析設定ページ
- 取得・生成失敗時に既存公開データを維持するフェイルセーフ
- JSON／CSV／画像だけで管理できる外部サービス非依存構成

外見用CSS、サイトカラー、画像、文章、テーマはNSWER専用で管理します。
