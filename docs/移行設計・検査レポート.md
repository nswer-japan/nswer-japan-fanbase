# NSWER JAPAN FB 移行設計・検査レポート

作成日: 2026-07-26

## 1. 調査対象

2つのZIPを展開し、ファイル構成、ページ、データ管理、生成スクリプト、自動更新、デザイン、画像資産、SEO、PWA、言語機能を比較しました。

- 高機能な基盤側: 約1,056ファイル
- 既存NSWERサイト側: 約258ファイル

既存NSWERサイト側には、現行ページに加えて過去差分、重複画像、作業用ZIPが含まれていました。このため、旧サイトへ機能を継ぎ足す方式ではなく、高機能な静的基盤を複製し、既存NSWER資産を選別移植する方式を採用しました。

## 2. 維持する機能

- GitHub Pagesでの静的公開
- スマートフォン、タブレット、PCのレスポンシブ表示
- ダーク、ライト、端末設定連動

- 共通ヘッダー、フッター、ナビゲーション
- サイト内検索
- お気に入り
- Web Share、X、LINE、URLコピー
- SEO、canonical、robots
- OGP、Xカード、ページ別OGP画像
- 構造化データ
- `sitemap.xml` と `robots.txt`
- PWA、ホーム画面追加、オフライン画面
- 404ページ
- YouTube公開情報取得
- 外部リンク検査
- スケジュールのGoogleカレンダー、ICS出力

## 5. 新しく作る管理方式

### 管理元

- `data/*.json`: 通常更新
- `data/csv/*.csv`: 表形式での一括更新
- `assets/`: 画像

### 生成物

- JSON互換の表示用JavaScript
- ニュース静的記事
- 音楽番組1位、Melon、Hanteo静的ページ
- 検索インデックス
- 共通ヘッダーとフッター

- SEOメタデータ
- ページ別OGP
- 構造化データ
- サイトマップ
- PWAキャッシュ
- スケジュールICS

### 更新の分離

- リポジトリデータ生成
- YouTube取得
- サイト検査
- 外部リンク検査
- 全体同期

各処理を別ワークフローにし、必要な用途だけ手動実行できるようにしました。

## 6. 作業順序

1. 2つのZIPを安全な作業場所へ展開。
2. 全ファイル一覧、拡張子、重複物、Actions、スクリプトを調査。
3. 維持機能と削除対象を分類。
4. 高機能な静的基盤を新しい作業ディレクトリへ複製。
5. 既存NSWERサイトからメンバー、作品、ニュース、記録、ガイド画像を選別。
6. サイト名、URL、説明、構造化データ、OGPをNMIXX用へ変更。
7. 管理JSONを内容別に分割。
8. 旧外部DB連携、旧管理画面、不要Actions、不要資産を削除。
9. NMIXX向けのページ、データ、画像を移植。
10. 対象外番組と不要投票アプリを削除。
11. YouTube自動取得を公式チャンネルの公開タブへ限定。
12. 自動取得失敗時の既存データ保護を実装。
13. テーマJSONからCSSを生成する処理を実装。
14. CSV取込、バックアップ、入力検査を実装。
15. 記録ページ、ニュース記事、SEO、OGP、PWAを再生成。
16. 各段階でJSON、構文、リンク、画像、禁止文字列を検査。
17. マニュアルを作成。
18. GitHub上書き用と完全版をZIP化し、ZIP内部を再検査。

## 8. 実装した安全策

- YouTubeは一時ファイル完成後にだけ置換。
- YouTube全取得失敗時は既存JSONを変更しない。
- 一部タブ失敗は記録して、取得できた公開情報を使用。
- Actionsの書込みジョブを同じconcurrencyグループへまとめる。
- Actions自身の生成コミットで再生成ループを起こさない。
- CSVが空、例示行、必須不足、日付不正なら取込を中止。
- CSV取込前に元JSONをバックアップ。
- 生成物と管理元を分離。
- 内部リンク検査と禁止文字列検査を公開前コマンドへ統合。
- 自動更新失敗でも直前の公開済みサイトを維持。

## 10. 最終検査方針

最終ZIP作成前に `bash scripts/run-prepublish-checks.sh` を実行し、生成、JSON、内部リンク、画像、禁止文字列、JavaScript、Node.js、Pythonのすべてが成功することを条件とします。

ZIP作成後は別ディレクトリへ試験展開し、次を再確認します。

- GitHub上書き用ZIPはファイルがZIP直下にある。
- 完全版ZIPは1つの親フォルダ内にまとまっている。
- `.github` とドットファイルが含まれる。
- 不要なキャッシュ、バックアップ、作業用ZIPが含まれない。
- 旧サイト固有データが含まれない。
- ジャケット、プロフィール、ニュース、ガイド画像を目視一覧でも確認する。
- ZIPテストが成功する。

実ブラウザでの最終確認は、GitHub Pages公開後にPCとスマートフォンの両方で行うことを推奨します。
