# リポジトリ完結型への変更記録

日付：2026-08-01

## 変更

- 外部CMS同期スクリプトを削除
- 外部CMS用GitHub Actionsを削除
- Token、データソースID、設定JSONを不要化
- 管理元を `data/*.json`、`data/csv/*.csv`、`assets/`へ統一
- YouTube全履歴自動取得は維持
- SEO、OGP、PWA、検索、多言語、記録生成、外部リンク検査を維持
- 更新状況ページをリポジトリ運用向けに変更
- 検査スクリプトへ外部CMS実行ファイルの残存確認を追加

## 設計方針

NSWER独自の外見を維持し、運営機能と安全性は高機能ファンベースサイトと同等にします。
